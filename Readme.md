# Advent of Code Solutions in Go

This repository contains my solutions to the [**Advent of Code**](https://adventofcode.com/) programming challenges, written in **Go**.

## Overview

The purpose of this repository is to practice problem solving and improve my understanding of Go. The solutions focus on writing clear, readable, and idiomatic Go code.

## Repository Structure

Each year has its own directory.

Within each year directory, each day has its own folder containing the solution for that day's puzzle.

## Running the Solutions

Install Go on your system, then navigate to the day you want to run and use:

```bash
go run .
```

## Notes

These are my personal solutions and may not always be the most optimized. The main focus is learning, problem solving, and writing clean Go code.

## About Advent of Code

[**Advent of Code**](https://adventofcode.com/) is an annual programming event created by **Eric Wastl**, featuring programming puzzles released throughout December.
